# Final publication data: P0-7F2 / P0-7F3

This directory is reserved for the publication-facing final matched-evaluation and seed-aware inference artefacts.

Scientific authority is defined by `../PUBLICATION_AUTHORITY_P0_7F2_P0_7F3.md`.

Publication-facing quantitative claims must use the P0-7F2 matched evaluation and P0-7F3 seed-block inference. Earlier exploratory or pre-correction result files elsewhere in the repository are retained only for provenance and must not be used as final manuscript evidence.

Final design: 12 independently trained controller-threshold-seed units; 50 deterministic evaluation episodes per cell; 600 controller episodes; 300 exactly matched PPO--shielded-PPO episode pairs; WEZ thresholds 3 deg and 5 deg; three independent training seeds; seed-block plus three-seed Student-t inference.
