# Legacy replay artefacts

This directory contains replay artefacts from an earlier seed-0 evaluation chain. They are retained only for historical traceability and are **not** publication-authoritative for the final P0-7F2/P0-7F3 manuscript.

The final publication-facing replay selections are documented in `../true3d_replays/PUBLICATION_REPLAY_SELECTIONS.csv` and use matched episodes (theta=3 deg, seed 2, episode 7), (theta=3 deg, seed 2, episode 40), and (theta=5 deg, seed 1, episode 33).

Do not use files in this directory to support final manuscript claims.
